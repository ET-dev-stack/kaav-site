# Brand logos

Drop each brand's logo file here (SVG preferred, PNG with transparent
background works too — keep them roughly the same visual weight, ~32px tall
when placed on the site).

Then add or edit its entry in `public/brands.js`, pointing `logo` at the
file you added, e.g. `logo: "logos/strawbees.svg"`.

If a brand doesn't have a logo yet, leave `logo: null` in brands.js — the
tile will show the name as text instead until you add one.
